# Publication-readiness checklist

This is a research completion checklist, not an assertion that the listed work is done.

- [ ] Novel question and locked primary endpoint, contrasted with existing literature.
- [ ] Ethics/consent/access permissions and real approval identifiers where applicable.
- [ ] Reconciled patients, samples, sections, technical replicates and clinical labels.
- [ ] Complete inclusion/exclusion flow and reasons; no silent loss of hard samples.
- [ ] Frozen reference, gene mapping, raw/processed data receipts and software environment.
- [ ] Real-cohort end-to-end execution with all logs, QC and source-data tables.
- [ ] Reviewed cell labels; malignant-cell claims supported by independent evidence.
- [ ] Enough independent patients; identifiable design; appropriate covariates and missingness plan.
- [ ] Prespecified statistical families, effect sizes, uncertainty and complete negative results.
- [ ] Spatial histology, graph, deconvolution convergence and reference sensitivity.
- [ ] Absolute orthogonal T-cell density endpoint measured and modeled as preregistered.
- [ ] Independent validation without patient leakage or optimized validation cutpoints.
- [ ] Functional perturbation and rescue where a causal claim is made.
- [ ] Patient-level sensitivity, batch checks and independent review of the analysis.
- [ ] Figure source data, units, patient n, scale bars, readable labels and explicit panel captions.
- [ ] Code release/tag and persistent archive DOI after validation; don't invent a DOI.
- [ ] Required data repositories, license review and journal reporting forms.
- [ ] Manuscript methods reflect what was actually performed, including deviations and failures.

The delivered synthetic figures are software examples and **must not be submitted
as patient-derived results**. The code can support a publication after the real study
meets these requirements; no “perfect code” or guaranteed acceptance claim is made.
